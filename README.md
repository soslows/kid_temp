# Дневник температуры ребёнка (kid-temp)

Простое приложение, чтобы записывать измерения температуры ребёнка во время болезни:
добавить измерение, увидеть историю и статистику (сколько измерений, максимум, последнее).

Данные хранятся только на этом устройстве (SharedPreferences приложения), никуда не отправляются.

## Как запустить

1. Установить зависимость (одна):
   pip install -r requirements.txt
2. Запустить приложение:
   python main.py

## Как устроен код

- `main.py` — экран и кнопки (интерфейс).
- `logic.py` — вычисления: разбор температуры, форматирование, статистика. Без интерфейса, поэтому легко проверяется.
- `test_logic.py` — проверки вычислений. Запуск: `python test_logic.py`

## Как проверить

`python test_logic.py` — все проверки должны напечатать «OK».

## Веб-версия (для установки на iPhone как PWA)

`flet build web` собирает статическую веб-версию (нужен Flutter SDK — flet скачает его сам при первой сборке).
На этом компьютере сборка не выполнялась: не установлен Flutter SDK.
Альтернатива без сборки: `flet run --web` поднимает веб-версию приложения локально.

## Известные упрощения

- Хранение и экспорт:
  - Записи хранятся в SharedPreferences (локальное хранилище приложения). Экспорта/резервной копии нет — при очистке данных приложения записи пропадут.
  - Данные привязаны к конкретному приложению/браузеру на устройстве; перенести записи на другой компьютер нельзя.
- Ввод:
  - Принимается и запятая, и точка («36,6» и «36.6») — это одно и то же.
  - Диапазон 30–45 °C: всё, что вне, считается опечаткой и не сохраняется.
  - Температура хранится как число, показывается с одним знаком после запятой.
- Записи:
  - Нет редактирования записей — только добавить и удалить (проще и надёжнее).
  - Две полностью одинаковые записи (одна минута, та же температура и заметка) неразличимы: удалится первая из них.
- Дата/время записи берётся из часов устройства в момент нажатия «Добавить»; вручную время измерения указать нельзя.
- Нет графика и напоминаний — код оставлен намеренно простым.
